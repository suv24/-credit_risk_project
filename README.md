📌 PROJECT OVERVIEW 
---------------------
This project builds a complete credit risk prediction model using Logistic Regression and Random Forest, focusing on both model performance and business interpretation.
It includes data cleaning, feature engineering, model training, evaluation, and insights for real-world lending decisions.
